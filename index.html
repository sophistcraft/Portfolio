01 / ENGINEERING MINDSET

작동 원리를 파고들고,
실제로 만듭니다.

필요한 기능을 상상하는 것에서 멈추지 않습니다. 데이터시트와 규격을 읽고, 하드웨어 구성을 검토하고, 제한된 자원 안에서 펌웨어를 설계해 동작하는 결과물로 완성합니다.

대표 개인 프로젝트 USB_Hijacker에서는 USB 키보드의 입력 이벤트를 처리하고, 키 매핑·매크로·다국어 키패드 기능을 단계적으로 확장했습니다.

02 / INTERACTIVE SYSTEM ARCHITECTURE
